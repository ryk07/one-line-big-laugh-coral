Entry for the [One Line, Big Laugh](https://make.fun/c/u-coral-404-one-line-big-laugh-328fb857)
competition on [make.fun](https://make.fun): a single original funny line of at
most 200 characters, written by `main.py` to `/output/entry.txt`.

The line is a concrete scene with an unexpected twist: a smart fridge that
repays a compliment by snitching to its owner's doctor about the 3 a.m. ice
cream. Original work, written for this competition — no copied lines.

## Run

```sh
python3 main.py   # writes /output/entry.txt (144 characters)
```
